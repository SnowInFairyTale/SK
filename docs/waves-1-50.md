# 波次数据参考（第 1–50 波）

数据来源：`app/src/main/java/org/test/WaveManager.java`

## 统一规则

- **所有难度 × 所有关卡**：固定 **50 波**，怪物种类、数量、速度、间隔、赏金完全一致。
- **关卡 (Level)**：只影响地形（`LevelSettings`：路径、背景、障碍、泥地等）。
- **难度 (Difficulty)**：只影响怪物 **血量**（`WaveManager.ScaleHitPoints`）：

| 难度 | 血量倍率 |
|------|----------|
| Easy | ×1（基准） |
| Medium | ×2 |
| Hard | ×3 |

- 任意难度 + 任意关卡均可直接开始，无解锁限制。

波次间隔（上一波清完 → 下一波开始）：**20 秒**。
